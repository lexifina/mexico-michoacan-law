Artículo 109. Cuando este Código no señale términos para la práctica de algún acto judicial, o para el ejercicio de algún derecho, se tendrán por señalados los siguientes:
I. Nueve días para interponer el recurso de apelación de sentencia definitiva;
II. Seis días para apelar de sentencia interlocutoria o auto;
III. Tres días para la celebración de juntas, reconocimiento de firmas, exhibición de documentos, dictamen de peritos; a no ser que por circunstancias especiales creyere justo el Juez ampliar el término, lo cual podrá hacer por tres días más; y,
IV. Tres días para todos los demás casos.
