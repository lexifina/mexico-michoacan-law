Artículo 1031. El perito queda autorizado para solicitar aclaraciones de las partes, requerir informes de terceros y obtener copias, planos o practicar consultas o experimentos. De igual manera, estará facultado para inspeccionar personas, lugares, bienes muebles o inmuebles, documentos y libros; obtener muestras para exámenes de laboratorio o experimentos o ilustrar sus dictámenes.
Las partes y terceros tienen obligación de darles facilidades para el cumplimiento de su misión y el juez les prestará el auxilio necesario para ese fin.
